# Contributing

Contributions are governed by Apache-2.0 and Developer Certificate of Origin 1.1 (`DCO.txt`). Every commit must include a `Signed-off-by: Name <email>` trailer created with `git commit -s`; the sign-off certifies the DCO for that contribution.

Keep changes inside this package's `PUBLIC_EXPORTS.json` boundary unless the product owner separately approves an export change. Do not add authority to approve or formally write, long-lived credentials, authoritative database access, private business policy, hidden network access, input/credential audit storage, third-party code or unverified compatibility claims. Declare every source, dependency, generated file and modification.

The repository is not currently accepting organization-external contributions or publishing this package externally. External publication and real third-party verification require separate authorization.

# Contributing

Contributions are governed by Apache-2.0 and Developer Certificate of Origin 1.1 (`DCO.txt`). Every commit must include a `Signed-off-by: Name <email>` trailer created with `git commit -s`; the sign-off certifies the DCO for that contribution.

Keep changes inside this package's `PUBLIC_EXPORTS.json` boundary unless the product owner separately approves an export change. Do not add credentials, production data, authoritative database access, approval authority, formal-write channels, hidden network access, third-party code, or ComfyUI-specific code. Declare every source, dependency, generated file and modification, and add focused tests.

The repository is not currently accepting organization-external contributions or publishing this package externally. A future contribution intake still requires separate authorization and review.

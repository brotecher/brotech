# Contributing

Contributions are governed by Apache-2.0 and Developer Certificate of Origin 1.1 (`DCO.txt`). Every commit must include a `Signed-off-by: Name <email>` trailer created with `git commit -s`; the sign-off certifies the DCO for that contribution.

Keep changes inside this package's `PUBLIC_EXPORTS.json` boundary unless the product owner separately approves an export change. Do not copy or derive ComfyUI Core, Frontend, Desktop, node, extension, patch, installer, updater or distribution code. Do not add credentials, automatic network access, authoritative database access, approval authority, formal-write channels, or claims based only on fixtures. Declare every external source and dependency before incorporation.

The repository is not currently accepting organization-external contributions or publishing this package externally. Real third-party combinations, external publication and distribution require separate authorization and review.

# @mojing/gateway-core

墨境原创的开放网关核心与参考边缘代理实现。网关执行目标允许列表、能力令牌受众／有效期／项目／权限校验、外部控制平面批准确认、nonce 重放保护和最小审计记录。

网关不会签发令牌、授予批准、持有或返回凭据、访问权威数据库、执行正式写入或决定商业路由。调用方必须在网关之外完成身份、策略和批准；返回值始终明确 `credentialsExposed: false` 与 `approvalGrantedByGateway: false`。

`ReferenceEdgeProxy` 只接受外部权威签发并由调用方完成验证的精确代理／主体／序列／目标／权限／有效期租约。它拒绝旧租约、撤销租约、离线命令、过期或超长命令、未验证签名、缺少外部批准、非法目标、超范围权限、超限载荷、重放和取消后的迟到结果。轮换租约立即使旧租约失效；审计只记录关联身份与决定，不保存载荷或凭据。

边缘传输由部署者注入，公共命令不接受 URL、主机名、证书或密钥，因此本参考实现本身不会打开网络、扫描内网、访问本机元数据或持有长期密钥。当前夹具只调用本地仿真传输，离线策略一律拒绝；它不连接真实设备、不证明工业安全，也不授权正式动作。

决策 19 将该制品（包括参考边缘代理）纳入采用 Apache-2.0 的开放中间层。当前 `private: true` 只用于阻止未获授权的组织外发布；本地夹具通过不代表生产安全、真实身份系统、真实边缘连接或公开发布验收。

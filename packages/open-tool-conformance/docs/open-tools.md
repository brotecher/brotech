# 墨境开放工具本地参考契约 0.1.0-fixture

本页说明 `@mojing/open-tool-conformance` 当前可重复运行的开放工具参考切片。它是仓库内的公开契约、参考实现和一致性夹具，不是对任何外部 MCP 或 A2A 修订的认证，也没有对外发布授权。实际外部协议修订只有在相应实现完成一致性测试后才进入兼容声明。

## 统一包头与升级

开放工具包头固定表达 Schema 身份与版本、命名空间、兼容范围、稳定对象身份、规范序列化版本、内容摘要、签名状态和扩展声明。`1.0.0` 与 `1.1.0` 固定夹具演示升级、弃用说明和回退：

- 普通未知扩展原样保留；
- 未知权限、副作用、批准、正式写入或物理动作扩展拒绝执行；
- 签名状态为 `not-configured` 时不得解释为已验证签名。

## 互操作角色

- MCP：工具发现/调用，以及经用户确认的 MCP 工具与墨境节点双向映射。
- A2A：独立 Agent 的发现、委托、进度、取消与制品交接。
- OpenAPI：普通系统接口调用。
- Webhook：普通事件接入；固定夹具记录验签、去重和重放拒绝结果。

四类入口都归一化为 `UnifiedInvocationRecord`，共同记录实际协议修订、权限申请与授予、外发、费用、副作用、取消/错误、幂等身份、审计引用及 `formalWrite: false`。

## 参考网关边界

独立包 `@mojing/gateway-core` 的 `ReferenceOpenGateway` 只接受目标允许列表以及限主体、受众、项目、目标、权限和有效期的能力令牌。它拒绝重放、未授权项目、非法目标、范围扩大、过期令牌和缺少外部控制平面批准的请求。返回记录始终声明：

同一独立包的 `ReferenceEdgeProxy` 以外部权威租约、精确租约序列、命令有效期、目标允许列表、权限、已验证签名结果、外部批准、在线状态、载荷大小、重放和取消边界协调注入式本地传输。租约轮换或撤销后旧租约不能继续调用；审计不保存载荷或凭据。当前只验证固定仿真传输，不连接真实边缘设备或网络，也不证明生产工业安全。

- 不暴露正式数据库凭据；
- 不由网关授予批准；
- 每次决定都有审计引用。

## 工具—节点映射

`mapMcpToolToNode` 要求明确确认，并保留工具版本、实际连接修订、输入输出 Schema、权限、外发、费用、副作用、取消、错误、普通扩展和撤销状态。`publishNodeAsMcpTool` 只发布用户选择的输入输出，不暴露其余节点或项目内部状态。未知安全扩展会阻止映射，`revokeMcpMapping` 阻止映射继续被视为可用。

## 本地一致性入口

运行：

```sh
pnpm --filter @mojing/open-tool-conformance test:unit
```

用户界面中的“能力管理中心 → 开放协议与参考网关”运行同一确定性夹具，并明确显示其隔离范围。固定合成费用单位、模拟身份和虚拟项目不能替代真实第三方实现、真实签名信任、生产安全或法律合规验收。

# @mojing/open-tool-conformance

墨境原创的开放工具中立契约、参考实现与隔离一致性夹具。它统一描述 MCP、A2A、OpenAPI 和 Webhook 的权限、外发、成本、副作用、取消、错误、幂等与审计语义，并提供包头迁移、工具—节点映射、A2A 任务和 Webhook 防重放参考实现。

本包不授予批准、不签发或持有密钥、不访问权威数据库、不执行正式写入，也不构成任何外部协议修订或第三方实现的认证。固定合成费用、模拟身份和隔离夹具只能证明本地确定性行为。

决策 19 将该制品纳入采用 Apache-2.0 的开放中间层。当前 `private: true` 只用于阻止未获授权的组织外发布；本地通过不代表公开发布或真实互操作验收。

详细契约见 [`docs/open-tools.md`](docs/open-tools.md)。
